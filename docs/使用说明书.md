## 1 工具简介

TFL Shell 生成工具用于自动化生成临床试验统计分析计划中的 Shell 文档（空壳表格/图形/清单）。统计师在 Web 界面配置每一条 TFL 的结构和格式，工具根据配置生成符合监管格式要求的 Word 文档。

**核心工作流：**

    浏览器编辑配置  →  保存并提交 Git  →  R 渲染生成 Word 文档  →  下载

**支持的输出类型：**

| 类型 | MacVar 值 | 说明 |
|------|-----------|------|
| 统计表 | PStab | 三线表，支持多级表头和分组行 |
| 数据清单 | RptList | 逐行列举原始数据 |
| 引用表格 | mtext | 输出"格式同表 XX" |
| KM 生存曲线 | KMplot | Kaplan-Meier 图 |
| 游泳道图 | Swimplot | 受试者治疗时间轴 |
| 瀑布图 | WaterfallPlot | 肿瘤缩小百分比 |
| 蜘蛛图 | Spiderplot | 各时间点肿瘤大小变化 |
| 折线图 | Seriesplot | 多组时序数据 |
| 森林图 | Forestplot | 亚组效应汇总 |

## 2 快速开始

### 2.1 环境准备（首次使用）

**Python 环境（命令行运行）：**

```bash
pip install streamlit pyyaml GitPython pandas openpyxl
```

**R 环境（在 R 中运行）：**

```r
install.packages(c("openxlsx", "officer", "flextable", "dplyr",
                   "survival", "survminer", "ggplot2", "ggpubr", "yaml"))
```

**Git 配置**（首次使用，编辑 `web/config.toml`）：

```toml
[git]
repo_path    = "D:/shell_tool"         # 改为实际项目路径
remote       = "origin"
branch       = "main"
author_name  = "张三"                  # 改为本人姓名
author_email = "zhangsan@example.com"  # 改为本人邮箱
```

### 2.2 启动界面

Windows 双击 `start.bat`，或在命令行运行：

```bash
streamlit run web/app.py --server.port 8501
```

浏览器会自动打开 http://localhost:8501。

### 2.3 第一次使用流程

1. 顶部工具栏填写**方案简称**（如 ISS、CSR_A）
2. 点击「**加载**」选择现有 YAML 或 Excel 配置文件；或点击「**新建空白**」从头创建
3. 在「📋 Config章节」标签页逐条编辑 TFL 配置
4. 在「🗂 Datasets」标签页为每条 PStab 行配置数据结构
5. 底部点击「**🚀 生成 TFL Shell**」预览输出
6. 确认无误后点击「**🔒 保存并提交 Git**」正式存档

## 3 界面总览

页面分为三个固定区域：

## 4 工具栏操作

### 4.1 方案简称

填写本次配置的方案标识，例如 ISS、CSR_A、IMM01-008。保存时文件名自动生成为 `config_<方案简称>_<时间戳>.yaml`。**此字段为必填，不填无法提交 Git。**

### 4.2 加载已有配置

**YAML 格式**（推荐）：从下拉列表选择 `config/` 目录中的 `.yaml` 文件，点击「加载」。

**Excel 格式**：分别选择 `config_*.xlsx`（主配置）和 `datasets_*.xlsx`（数据结构），点击「加载」。系统会根据 config 文件名自动猜测对应的 datasets 文件。

### 4.3 新建空白

清空当前所有配置，创建一个空白方案，适合从头开始制作新的 TFL Shell。

### 4.4 底部操作按钮

| 按钮 | 功能 | 说明 |
|------|------|------|
| 💾 保存草稿 | 保存到本地临时文件 | 不提交 Git，用于中途保存 |
| 🚀 生成 TFL Shell | 调用 R 渲染 Word 文档 | 校验通过后可用，成功后出现下载按钮 |
| 🔒 保存并提交 Git | 写入 YAML + Git commit/push | 需填写方案简称且校验通过 |

## 5 Config 章节标签页

这是主要工作区，左侧为**章节导航树**，右侧为**TFL 卡片编辑区**。

### 5.1 章节导航树（左侧）

导航树按 Section no 分组，每个章节显示该章节下的 TFL 数量。

**操作：**

- **点击章节名** — 筛选右侧只显示该章节的 TFL
- **▼ / ▶** — 折叠/展开章节节点
- **「表格」按钮** — 切换右侧为该章节的批量表格编辑视图
- **「全部」** — 取消筛选，显示所有 TFL

### 5.2 卡片编辑（默认视图）

每条 TFL 以卡片形式显示，支持三种状态：

**折叠状态（默认）**

显示摘要行：序号、章节号、表号、标题、MacVar 类型。点击标题区域展开该卡片。

**展开状态（Level 1）**

显示所有主要编辑字段，以及：

- 📎 Datasets 嵌入面板：快速查看当前关联的数据集（前20行），点击「编辑完整 Datasets ▶」跳转到 Datasets 标签页
- 「展开更多 ▼」：显示脚注字段（footnote1-7）和次要字段

**专注模式（Focus）**

点击卡片头部的「🔍」按钮进入专注模式，右侧只显示当前卡片，其余隐藏。点击「退出🔍」或左上角「← 返回表格」退出。

### 5.3 卡片按钮说明

| 按钮 | 位置 | 功能 |
|------|------|------|
| 收起▲ | 左侧 | 折叠当前卡片 |
| 🔍 / 退出🔍 | 左侧 | 进入/退出专注模式 |
| ▲ | 中部 | 上移当前 TFL（调整顺序） |
| ▼ | 中部 | 下移当前 TFL |
| + | 中部 | 在当前卡片后插入新空白 TFL |
| ⋮ | 右侧 | 展开操作菜单（复制 / 删除） |

### 5.4 批量表格视图

在导航树中点击章节的「表格」按钮，右侧切换为该章节的紧凑表格视图，每行对应一条 TFL，可直接行内编辑主要字段。

- **点击标题列按钮** — 跳转到该 TFL 的专注模式
- **勾选复选框 + 批量删除** — 一次删除多条 TFL

### 5.5 添加新 TFL

**方法一**：点击任意卡片的「+」按钮，在该卡片下方插入新空白 TFL。

**方法二**：在批量表格视图中点击「+ 新增一行」。

新插入的行 SeqNum 自动递增，Section no 和 Section title 默认继承前一行。

## 6 Datasets 标签页

Datasets 标签页用于编辑每条 TFL 关联的数据结构（变量列表）。

**前提**：先在「Config章节」标签页点击某条 PStab 行的卡片使其展开（展开即选中），再切换到本标签页。

### 6.1 PStab 类型数据集（表格型）

每条 PStab 行对应一个数据表，字段如下：

| 字段 | 说明 |
|------|------|
| Class | 分组行标签（空=普通数据行） |
| Label | 行标签文字，支持富文本标记 |
| Order | 缩进层级（0-5），控制行缩进量 |
| Aval | 统计量展示公式，如 `n (xx.x%)` |
| exclude | 1=不生成此行，0=正常生成 |
| BlankCol | 指定哪些列留空，如 `1|2|3` |

**变量类型模板**：点击行的「类型」下拉选择变量类型（连续变量、分类变量等），系统自动填充标准子行（如 Mean (SD)、Median 等），避免手动逐行录入。

### 6.2 RptList 类型数据集（清单型）

MacVar 为 RptList 时，需在 list 工作表中配置：

| 字段 | 说明 |
|------|------|
| ListName | 清单名称 |
| Byseq | 排序序号 |
| Byorder | 升序(1)或降序(-1) |
| Lvalable | 字段显示标签 |

### 6.3 新建数据表

在「新建数据表名」输入框填写表名（如 `t_demo`），点击「新建数据表」，系统创建空白表格供编辑。填写 `list` 则创建清单型结构。

## 7 项目总览标签页

提供当前配置的全局视图，不可在此标签页修改数据。

### 7.1 章节统计表

按 Section no 分组汇总各章节中表/图/列表的数量，章节号按数值排序（14.1 < 14.2 < 14.10），最后一行为合计。

### 7.2 快速导航

每个章节对应一个按钮，点击后自动切换到「Config章节」标签页并筛选该章节。

### 7.3 最近渲染状态

显示最近一次「生成 TFL Shell」的结果：

- 尚未渲染：本次会话还未执行过生成
- ✅ 渲染成功：显示耗时和文件大小，并提供下载按钮
- ❌ 渲染失败：显示错误摘要

---

## 8 模板配置标签页

用于管理系统级模板配置，通常由项目负责人初次设置后不需频繁修改。

### 8.1 变量类型模板

配置「连续变量」类型自动扩展的子行（Label + Aval 对）。点击「保存模板」后在 Datasets 编辑器中选择「连续变量」类型时自动填充这些行。

### 8.2 Config 模板配置

**Section 映射**：预定义章节号与章节标题的对应关系。新增 TFL 时，填写 Section no 后 Section title 自动填充。

**pop 选项**：预定义分析集下拉选项（如 FAS、PPS、Safety Set），供 pop 字段使用。

**字段显示级别**：控制每个字段在卡片展开态中的可见性：

- 一级：展开卡片时直接显示
- 二级：在「展开更多」区域显示
- 不显示：隐藏该字段（必填字段强制显示，不可设为不显示）

## 9 生成 TFL Shell 文档

### 9.1 前置检查

底部状态栏显示校验结果。常见校验错误：

| 错误信息 | 原因 | 解决方法 |
|----------|------|----------|
| 第 N 行：MacVar 不合法 | MacVar 填写了不支持的值 | 从下拉框选择合法值 |
| 第 N 行：Datasets 未定义 | Datasets 字段填的表名不在数据集列表中 | 在 Datasets 标签页新建对应表 |
| 第 N 行：SeqNum 重复 | 有两行序号相同 | 修改其中一行的 SeqNum |
| 请先填写方案简称 | 顶部方案简称为空 | 填写方案简称 |

### 9.2 生成流程

1. 校验通过后，点击「🚀 生成 TFL Shell」
2. 系统将配置序列化为 YAML，调用 R 脚本渲染
3. 渲染耗时约 10-60 秒（取决于 TFL 数量）
4. 成功后出现「📥 下载 output.docx」按钮，点击下载

### 9.3 渲染失败处理

失败时界面显示 R 错误摘要。点击「查看 R 完整日志」可获取详细错误信息。

如错误提示定位到某 SeqNum，可点击「📍 定位到 Seq N」按钮快速跳转到对应 TFL 卡片。

常见 R 错误：

- `object 'xxx' not found`：Datasets 中引用的列名在数据集中不存在
- `subscript out of bounds`：数据集行数为 0，需在 Datasets 中添加数据行
- R 未安装 / 包未安装：检查 R 环境和依赖包

### 9.4 保存并提交 Git

确认输出文档无误后，点击「🔒 保存并提交 Git」：

1. 将当前配置序列化为 YAML 文件（`config/<方案简称>_<时间戳>.yaml`）
2. 自动执行 git add + git commit + git push
3. 成功后提示文件路径和 commit 信息

若 Git push 失败（网络问题），文件已写入本地，提示手动 push。

## 10 字段填写参考

| 字段 | 必填 | 说明 | 示例 |
|------|------|------|------|
| SeqNum | ✅ | 序号，决定文档中的顺序 | 1, 2, 3 |
| Section no | ✅ | 章节号 | 14.1, 14.2.1 |
| Section title | | 章节标题，可从模板自动填充 | 人口学特征 |
| cat | | TFL 类别，用于总览统计 | 表 / 图 / 列表 |
| table no | | 表/图/列表编号 | 14.1.1, 16.2.1 |
| title | | 表/图/列表标题，支持富文本 | 人口学特征汇总（FAS） |
| pop | | 分析集，从下拉选择 | FAS, PPS |
| MacVar | ✅ | 输出类型 | PStab, KMplot |
| Datasets | | 对应的数据集名称 | t_demo, t_ae |
| Trtlab | | 治疗组列标签，`\|` 分隔 | A组\|B组\|合计 |
| Subgrp | | 子组标签，`\|` 分隔 | 男性\|女性 |
| footnote1-7 | | 脚注（最多7条），支持富文本 | FAS: 全分析集 |
| RefTFL | | mtext 引用的表号 | 14.1.1（MacVar=mtext时） |

**MacVar 类型选择指南：**

- 有数据行的统计表 → `PStab`，需配置 Datasets
- 逐受试者的原始数据清单 → `RptList`，需配置 list 工作表
- "格式同表XX"的占位符 → `mtext`，填 RefTFL 引用目标表号
- 生存分析图 → `KMplot`
- 受试者治疗时间轴 → `Swimplot`
- Best Response 瀑布图 → `WaterfallPlot`

## 11 富文本标记语法

在 title、footnote1-7、Label、Aval 等任意文本字段中，可使用以下标记输入上下标：

| 标记语法 | 效果 | 示例 |
|----------|------|------|
| `^[文字]` | 上标 | `IC50^[a]` 显示为 IC50 上标a |
| `_[文字]` | 下标 | `H_[2]O` 显示为 H 下标2 O |
| `[文字]` | 普通方括号，直接写 | `[FAS]` 显示为 [FAS] |

注意：只有 `^[` 和 `_[` 触发特殊格式，单独的 `[` 不会被解析。

## 12 常见问题

**Q：界面加载后是空白，没有任何 TFL 数据？**

A：正常现象，点击「新建空白」创建空配置，或点击「加载」加载现有配置文件。

**Q：保存时提示"Git push 失败"？**

A：文件已写入本地，不影响配置保存。可手动在项目根目录运行 `git push` 推送。

**Q：渲染失败，提示找不到 Rscript？**

A：确认 R 已安装并添加到系统 PATH。Windows 下通常在 `C:\Program Files\R\R-x.x.x\bin\` 目录，需添加到环境变量。

**Q：生成的 Word 文档中表格列数不对？**

A：检查 Trtlab 字段的 `|` 分隔数量是否与 Datasets 中配置的列数一致。

**Q：想调整 TFL 之间的顺序？**

A：在卡片视图中点击 ▲▼ 按钮逐步移动；或直接修改 SeqNum 数值（文档生成顺序以 SeqNum 从小到大排列）。

**Q：如何批量删除某章节下的 TFL？**

A：在导航树点击章节的「表格」按钮切换到表格视图，勾选要删除的行，点击「批量删除」。

**Q：config.toml 里填了 Git 信息，但提交后看不到 push 记录？**

A：检查 remote 是否正确配置（`git remote -v` 验证），以及网络是否可以访问远程仓库。建议配置 SSH Key 或 Git Credential Manager。
