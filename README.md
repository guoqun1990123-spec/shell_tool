# Shell文档自动生成工具

基于R语言开发的临床试验统计分析报告（Shell）自动生成工具。

## 功能特性

- 支持表格（Table）和清单（Listing）自动生成
- 支持多级表头（治疗组 + 二级分组）
- 支持缩进和分组显示
- 支持额外列和访视转置
- 自动处理脚注和编程说明
- 基于Word模板，保持格式一致性

## 使用方法

### 1. 准备输入文件

**config.xlsx**：配置表，每行定义一个TFL
- 必填列：`Section no`, `table no`, `title`, `pop`, `Datesets`, `MacVar`, `Trtlab`
- 可选列：`Subgrop`, `Adcols`, `Varlab`, `Labparm`, `footnote1-7`, `PgmNote`

**datasets.xlsx**：数据结构定义
- 表格型工作表：包含`Class`, `Label`, `Order`, `Aval`等列
- list工作表：包含`ListName`, `Byseq`, `Byorder`, `Lvalable`等列

**shell.docx**：Word模板文件
- 定义封面、页眉页脚、字体样式等格式

### 2. 运行脚本

```r
source("run_example.R")
```

或手动调用：

```r
source("R/generators/generate_shell.R")

generate_shell(
  config_file = "config/config.xlsx",
  datasets_file = "config/datasets.xlsx",
  template_file = "templates/template.docx",
  output_file = "output/output_shell.docx"
)
```

## 配置说明

### config.xlsx关键列

| 列名 | 说明 | 示例 |
|---|---|---|
| Datesets | 数据集名称 | demo, ae, enroll |
| MacVar | 宏类型 | PStab, RptList |
| Trtlab | 治疗组标签 | 试验组\|对照组\|合计 |
| Subgrop | 二级分组 | 所有级别\|≥3级 |
| ByseqL | 清单编号 | bases = 3 |

### datasets.xlsx结构

**表格型（demo/ae/lab等）：**
- `Class`：分组编号
- `Label`：行标签
- `Order`：缩进级别（0-5）
- `Aval`：占位值
- `exclude`：排除标记（1=不显示）
- `BlankCol`：空白列（如"1|2|3"）

**清单型（list工作表）：**
- `ListName`：清单名称
- `Byseq`：清单编号
- `Byorder`：列顺序
- `Lvalable`：列标签

## 注意事项

1. Excel文件必须包含指定的工作表名称
2. config中的`Datesets`必须与datasets中的工作表名对应
3. 清单类型必须在datasets中包含"list"工作表
4. Word模板文件必须存在且格式正确
